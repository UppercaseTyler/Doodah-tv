The Melbourne camera uses the Zoos Victoria organization icon. Holnicote uses National Trust branding. Small square site/app icons were chosen where full logos were available only as SVG or AVIF. All selected images were fetched over HTTPS and checked as PNG files; Plex rendering still needs verification after deployment.

Missing or blank `logo` values and missing local files use the HTTPS Doodah logo. Remote URLs are passed through: a later outage or URL change at the image host does not automatically trigger fallback.
